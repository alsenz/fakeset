description: End-to-end statistical tests for the corporate-registry and insurance examples using scipy and polars.
---

fakeset ships a Python pytest suite in `tests/statistical/` that exercises both
bundled examples end-to-end and verifies distributional correctness of the
generated Parquet files.

## Running the tests

```bash
# one-time setup
pip install pytest polars scipy

# run all statistical tests (~62 tests, takes ~10 s)
pytest
```

`pytest.ini` at the repo root configures test discovery — no arguments needed.

## What is tested

The suite runs both examples (building the release binary once via `cargo build
--release` if needed) and then checks the output across two tiers.

### Hard invariants

These always hold regardless of randomness and will catch any regression
immediately:

| Check | Datasets |
|---|---|
| Numeric fields within declared `range` | policies, contracts, claims, micro/small/medium/grants |
| Variant columns restricted to their declared value set | policies, contracts |
| Referential integrity (`ref:` fields point to valid rows) | contracts→customers, premiums→contracts, claims→contracts, directors→individuals, smes→orgs, micro/small→smes, grants→micro |
| Expression result = formula (`net_payout = claim_amount - deductible`) | claims |
| List cardinality within declared `min`/`max` | contracts.covered\_policies, organisations.directors |
| Outer-scoped list ref (`director.employer == org.company_name`) | organisations |
| Lower-cover partition identity (`micro + small + medium == smes`) | corporate-registry |
| SME IDs disjoint across size classes | corporate-registry |
| All integer range values generated (coverage check) | micro.employee\_count |

### Statistical soft invariants

These use established tests at **α = 0.01** (1% false-positive rate per test).
A failure here most likely indicates a genuine regression; re-run once to rule
out a random false alarm before investigating.

| Check | Test | Datasets |
|---|---|---|
| Include ratios match declared values | Binomial | contracts, premiums, claims, directors, smes, micro, grants |
| Variant frequency distributions match declared ratios | χ² goodness-of-fit | contracts.status |
| Numeric values consistent with Uniform[min, max] | Kolmogorov–Smirnov | annual\_premium, claim\_amount, deductible, base\_premium, grant.amount |

Tests skip automatically when the sample is too small for the chosen statistic
(e.g. the KS test for grants when fewer than 15 rows are generated, or the χ²
test when any expected cell count falls below 5).

## Known bugs documented by the suite

Eleven tests are currently marked `xfail` because they expose pre-existing
bugs — they document what *should* work once the bugs are fixed.  The
`strict=True` markers will automatically flip to test failures once the
underlying bug is resolved, turning them into reliable regression detectors.

**BUG-VAR** — Field-level variant values (e.g. `billing_period: monthly/quarterly/annual`)
are not applied when a dataset is a member of another dataset's lower cover group.
The typed stub generated by `expand_field_variants` has no `value` or `generator`,
so it falls through to random string generation.
*Affects:* premiums, claims (both include contracts).

**BUG-REF (first-child-wins)** — For overlap segments where two lower cover members
both appear (e.g. a contract row that belongs to both the premiums and claims subsets),
`grow_parent_from_children` inherits the parent's shared field (e.g. `contract_id`) from
whichever child is first in `child_batches` — determined by HashMap iteration order.
The other child's on-disk rows were generated with different values for that field and
will not match the parent.
*Affects:* `claims.contract_id` and `claims.customer_id` in the `{premiums ∩ claims}`
overlap segment (~34% of contract rows).  Non-deterministic: may pass or fail across runs.

## File layout

```
tests/statistical/
  conftest.py              session-scoped fixtures (build binary, run examples, load DataFrames)
  test_insurance.py        insurance example checks
  test_corporate_registry.py  corporate-registry checks
pytest.ini                 pytest configuration (testpaths, warning filters)
```

## Dependencies

| Package | Purpose |
|---|---|
| [polars](https://pola.rs) | Fast Parquet reading (pyarrow 15+ is incompatible with parquet-rs 58.x) |
| [scipy](https://scipy.org) | `binomtest`, `chisquare`, `kstest` |
| [pytest](https://pytest.org) | Test runner |
