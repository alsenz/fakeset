## Synopsis

```
fakeset [OPTIONS] <PATHS>...
```

`PATHS` is one or more files and/or directories containing YAML dataset
definitions. Directories are searched recursively for `.yaml` and `.yml` files.

## Options

### `--output <DIR>` / `-o <DIR>`

Directory to write generated output files into.

**Default:** `output`

```bash
fakeset definitions/ --output ./generated-data
```

### `--output-format <FORMAT>`

Override the output format for every dataset. Takes precedence over the
per-dataset `format:` declaration in the YAML.

**Values:** `parquet`, `csv`, `json`, `jsonl`

```bash
fakeset definitions/ --output-format csv
```

### `--print-dag`

Print the DAG with field details **before** the rewrite pass, then exit.
Useful for verifying include structure and field definitions before the
type-resolution pass modifies them.

```bash
fakeset definitions/ --print-dag
```

### `--print-rewritten`

Print the DAG with field details **after** the rewrite pass (resolved types
and merged constraints), then exit. Useful for debugging ref resolution and
constraint merging.

```bash
fakeset definitions/ --print-rewritten
```

### `--print-plan`

Print the execution plan — row counts, lower-cover segments, and inherited
field wiring — then exit. Useful for verifying Bernoulli segmentation and
understanding what the executor will generate.

```bash
fakeset definitions/ --print-plan
```

### `--scale <FACTOR>`

Multiply all dataset row counts by `FACTOR`.

- **Scale down** (`< 1.0`): produces a proportional sample of the configured data volume.
  For generated datasets the `rows:` count is multiplied. For import datasets the hash-ring
  segment is narrowed so only the proportional fraction of the file is used.
- **Scale up** (`> 1.0`): increases data volume. Only permitted when every import dataset
  already uses a ring that leaves unused file rows. The maximum allowed scale factor is
  `(1 − ring.start) / ring_span` for each import; fakeset rejects the run if any import
  cannot accommodate the requested scale.
- Datasets whose row count is derived from parents (via `include:`) are not scaled directly —
  they inherit the adjusted count from their scaled parents automatically.

**Type:** floating-point number

```bash
# 10% sample
fakeset definitions/ --scale 0.1

# 50% larger than configured
fakeset definitions/ --scale 1.5
```

### `--seed.ring <SEED>`

Seed for the import hash ring. When set, the partitioning of imported files across ring
slices is fully deterministic — the same seed and schema will always produce the same
assignment of file rows to ring positions.

When omitted, a random seed is chosen at startup. This means each run partitions the
imported file differently, which is usually fine for one-off synthetic data generation
but unsuitable for reproducible benchmarks or regression tests.

**Type:** 64-bit unsigned integer

```bash
# Reproducible import partitioning
fakeset definitions/ --seed.ring 42
```

## Examples

```bash
# Generate from a single file
fakeset policies.yaml

# Generate from a directory
fakeset ./definitions/

# Mix of files and directories
fakeset ./definitions/ extra_dataset.yaml --output ./output

# Override all output to CSV
fakeset ./definitions/ --output-format csv --output ./csv-output

# Inspect the execution plan
fakeset ./definitions/ --print-plan
```
